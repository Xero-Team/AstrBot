## [4.28.1] - 2026-09-11

### Added

- Mount instance-scoped high-risk tools on IM when the sender is bound as
  `instance_operator` or above on that config, without Dashboard step-up.
  `/session info` exposes the authorization subject for that binding. (#85)
- Add dedicated OpenCode Go Chat Completions, Messages, and Responses
  Provider types. Do not retarget official OpenAI, Anthropic, or OpenAI
  Responses sources at the Go API Base. (#82)
- Align personal WeChat (`weixin_oc`) with the official openclaw-weixin
  channel: QR pairing, IDC redirect, Silk outbound voice, quote
  reconstruction from local cache, 4000-character text split, tool-call
  progress items, and streaming coalesce. (#80)
- Assemble the main-agent tool catalog once from Skill `tools:`, Persona
  policy, and social-surface hard-strip. `read_skill` reads a frozen
  request snapshot; `SKILL.md` no longer implies Shell. (#73, #75)
- Export `TextPart.mark_as_temp` on `astrbot.api.provider` so plugins can
  append request-only extra user content without importing `astrbot.core`.
  (#83)
- Add BTW dual-loop execution for conversations and explicit `/work` tasks.
  Conversation and work loops can use separate models, constrained Computer
  Use runtimes, and independent Plugin, MCP, and Skill visibility. Work
  acknowledgements, status, cancellation, detached delivery, and failure
  redaction are tied to the originating session. (#136, #145)
- Add Telegram interactive callback buttons with one-shot, scoped tokens and
  normalized callback events. Telegram explicitly ingests supported message,
  channel-post, business-message, and callback updates, including topic-aware
  session targets. (#113, #167)
- Add Telegram media and mention normalization, album aggregation, topic
  routing, native command-menu reconciliation, proxy-aware clients, and
  bounded outbound delivery retries. (#115, #116, #117, #118, #119, #120,
  #121, #163, #164, #165, #166)
- Add knowledge-base document identities and canonical URL identities.
  Re-importing a matching file or URL replaces the document, unchanged
  content skips embedding, stored sources can be reindexed, and knowledge
  base source blobs are included in backups. Ingestion tasks expose durable
  progress and terminal states. (#91, #100, #102)
- Add IkunCode as a built-in Chat Completions provider. (#151)
- Add a daily optional GHCR nightly image workflow for the fork.

### Changed

- Route `prompt_prefix`, cron/background wake prompts, and tool-loop
  notices through one logic-free `{{name}}` interpolator. T2I Jinja2 stays
  isolated. (#74)
- Skill frontmatter `tools:` is a filter of registered names, not a grant.
  Community `allowed-tools` is ignored. (#73)
- WebChat shows reasoning by default and lets each request, regeneration, or
  thread override reasoning display from the composer menu. (#10020)
- Project workspace text previews reuse the Dashboard Shiki highlighter and
  follow the active light or dark theme. Binary files keep metadata-only
  previews. (#10023)
- Dashboard numeric fields and object editors enforce declared slider bounds
  for both slider and text input paths. The Dashboard bundle also removes
  unused font and diagram assets. (#10034, #10037)

### Fixed

- Send the OpenCode Go session header on auxiliary Provider calls. (#82)
- Keep Weixin OC streaming and media sends on the official channel path.
  (#80)
- Treat a missing `prompt_prefix` template as empty instead of failing.
  (#74)
- Freeze Skill snapshot files, lock catalog reingest, lock sandbox reads,
  and strip tools that were never stepped. (#73)
- Ignore macOS ``PermissionError`` when signalling an already-exited
  managed-shell process group during shutdown.
- Lark private sends remember the known chat ID and retry there when a private
  open-ID send is rejected, without duplicating successful deliveries.
  (#10018)
- Deliver final reasoning and text when a streaming Agent response contains no
  incremental events, preserving the normal streaming protocol. (#10025)
- Space concurrent knowledge-base URL-cleaning requests according to the
  configured RPM instead of releasing all waiters in one burst. (#10015)
- Preserve WebChat session titles when platform history is the only source,
  batch console log rendering to avoid UI freezes, continue conversation
  deletion after resolving the persisted current conversation, and avoid
  sending Dashboard credentials cross-origin. (#9983, #9988, #10003, #10007)
- Keep active-agent cron failures visible when a runner ends in `ERROR`, and
  harden web-search field, error-code, and parameter handling. (#9979, #9987)
- Sanitize cron job IDs before writing them to logs, continue Dashboard exports
  when an optional lookup record is missing, and restore the runtime container
  tool contract.
- Keep Telegram reply identity and UTF-16 mention offsets, merge album
  captions, split oversized group streams, retain accepted streaming receipts
  after submission errors, and restrict draft fallback to content errors.
- Preserve Telegram private-topic routing and complete the Dashboard Telegram
  configuration translations.
- Use `NullPool` for SQLite async engines on affected platforms and release
  knowledge-base ingestion capacity on cancellation. (#92, #102)

### Documentation

- Document OpenCode Go source types under `/providers`.
- Document Weixin OC official-channel login, media, quotes, and streaming.
- Document Skill catalog assembly, `read_skill`, and IM
  `instance_operator` instance tools.
- Document plugin relative imports, stacked command-filter AND, and
  `TextPart.mark_as_temp` on the plugin SDK guides.

### Maintenance

- Bump Python, Dashboard, and docs dependencies. Keep TypeScript 6.0.3
  because vue-tsc still lacks TypeScript 7. Cap `websockets` below 16 for
  lark-oapi and `mcp` below 3. (#71)
- Add `numba` and `polars` to the agent execution dependency surface and keep
  CI installation able to fall back from the configured package mirror to
  PyPI when the mirror is unavailable.
- Continue cross-platform CI coverage for Linux, macOS, and Windows, including
  Windows watchdog and managed-shell checks.

### Fork Deviations

- Did not apply upstream desktop-managed stale WebUI rejection (#9898).
  This fork does not ship AstrBot Desktop or download Dashboard packages.
- Upstream release wording and upstream-only artifact links are not copied
  verbatim; this changelog describes the features present in the fork.
- The ChatUI settings/composer redesign from upstream #10021 was reverted
  before this branch was published; only the independently integrated
  reasoning toggle and workspace preview behavior remain.

### 新增

  工具且不走 Dashboard step-up。`/session info` 给出用于绑定的授权主体。
  (#85)
- 新增 OpenCode Go Chat Completions、Messages、Responses 三个专用来源。
  不要用官方 OpenAI / Anthropic / OpenAI Responses 改 API Base 去接 Go。
  (#82)
- 个人微信（`weixin_oc`）对齐官方 openclaw-weixin：扫码配对、IDC 跳转、
  Silk 出站语音、本地缓存还原引用、4000 字拆分、工具进度条、流式合并。
  (#80)
- 主 Agent 工具目录一次装配：Skill `tools:`、人格策略、社交表面硬裁。
  `read_skill` 读请求级冻结快照；`SKILL.md` 不再隐含 Shell。 (#73, #75)
- 插件 SDK `astrbot.api.provider` 导出 `TextPart.mark_as_temp`，可追加仅
  本轮的 extra user content，不必导入 `astrbot.core`。 (#83)
- 新增 BTW 双循环与显式 `/work` 任务：对话和工作循环可使用不同模型，并分别
  配置 Computer Use、插件、MCP 和 Skill 可见性；确认、状态、取消、脱离回送和
  失败脱敏都绑定到发起会话。 (#136, #145)
- Telegram 支持交互回调按钮，并规范化消息、频道帖子、Business 消息和回调
  update 的摄入；会话目标支持主题路由。 (#113, #167)
- Telegram 增加媒体与 mention 规范化、相册聚合、主题路由、原生命令菜单同步、
  代理感知客户端和有界出站重试。 (#115, #116, #117, #118, #119, #120,
  #121, #163, #164, #165, #166)
- 知识库支持文档身份和规范化 URL 身份：重复导入会替换文档，未变化内容跳过嵌入，
  可对已保存源文件重建索引，备份包含源文件，导入任务提供持久进度和终态。 (#91,
  #100, #102)
- 新增 IkunCode 内置 Chat Completions 提供商。 (#151)
- 新增每日可选的 GHCR nightly 镜像工作流。

### 变更

- `prompt_prefix`、定时/后台唤醒提示和工具循环通知统一走无逻辑
  `{{name}}` 插值。T2I 仍用 Jinja2。 (#74)
- Skill 前言 `tools:` 只过滤已注册工具名，不是授权。社区
  `allowed-tools` 会被忽略。 (#73)
- WebChat 默认显示 reasoning，可在输入框菜单中为本次请求、重新生成或线程单独
  切换。 (#10020)
- 项目工作区的文本预览改用 Dashboard Shiki 高亮并跟随浅色/深色主题；二进制文件
  仍只显示元数据。 (#10023)
- Dashboard 数字字段和对象编辑器在滑块与文本输入路径都遵守声明的边界，并移除
  未使用的字体和图表资源。 (#10034, #10037)
