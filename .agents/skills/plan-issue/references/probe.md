# Clarify material choices

Use this only when the request and repository evidence leave a decision that
changes scope, behavior, architecture, or acceptance.

Explain the decision, recommend an option with its tradeoff, and ask a focused
question. Continue independent research while waiting. Reuse answers already
given in the conversation. Do not quiz the user on repository facts or require
framing approval, scores, a fixed question count, or an explicit skip phrase.

Choose routine implementation details yourself and state relevant assumptions
in the plan. Compare alternatives only when each solves the actual request;
do not invent a redesign to fill a template. If an answer is essential,
identify the dependent part and complete the rest of the plan first.

Record useful answers in the plan. A separate `QUESTIONS.md` is optional for
long investigations. Existing authorization to implement carries through
planning; a planning-only request does not authorize implementation.
