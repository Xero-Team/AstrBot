## [4.30.0] - [WIP]

This release covers changes merged after **v4.29.1**. It includes breaking toolchain and built-in tool changes; read **Changed** before upgrading.

### Added

- Dashboard appearance: server-persisted landscape and portrait wallpaper libraries, upload validation and thumbnails, wallpaper-derived theme colours, random-on-open and scheduled rotation, cross-tab synchronisation, and refreshed mobile layouts across tables, trace, session management, and dialogs. Wallpaper assets and appearance choices are included in WebUI backups. (#369)
- Trace: message traces now persist to bounded SQLite history (`data/logs/traces.db`, 80 MB target, 7-day retention) with server-side search, filtering, and pagination. The explorer adds grouped timelines, token usage, trace/span log correlation, and trace-aware storage cleanup; recording and budget controls live under **Settings → General → Logs**. (#10614)
- Diagnostics export: the new `Export diagnostics` action and `GET /api/v1/logs/export` build one ZIP from disk and rotated logs, custom log paths, cached logs, trace history, configuration and routes, plugin status, and environment details. Time ranges and redaction are selectable, only dashboard administrators can download, and one export runs at a time. (#10418, #10659)
- Backups now cover scheduled tasks, provider usage statistics, UMO aliases, OpenAPI access keys, and MCP server configuration. TOTP trusted devices are excluded from export and cleared on replace restore. (#10644, #10661)
- Docker: added `compose-with-searxng.yml`, which starts AstrBot and a loopback-published SearXNG sidecar with generated settings and JSON search enabled. Use `http://searxng:8080` as the instance URL. (#686)
- Local sandbox hardening: nested per-role network, filesystem, and Unix-socket policies now drive an authenticated per-invocation HTTP/SOCKS proxy, host-side DNS pinning, Linux bridge/seccomp socket isolation, launch-time path masks, macOS Seatbelt parity, and the same deny policy for file tools and grep. Configuration revision 6 migrates the flat `allow_network` key once. Native administrator execution remains unsandboxed, and the documented limitations include launch-time globs, preexisting hard-link aliases, and required `rg`/backend fail-closed behavior.
- ChatUI: per-request `flags` now control streaming, reasoning, inline GenUI, and the ChatUI default system prompt for SSE, regenerate, and WebSocket requests. (#365)

### Changed

- **Breaking:** Python 3.15.0 is now the source, CI, and container baseline; Python 3.14 and earlier are unsupported. `silk-python` builds from a pinned upstream source with `USE-CYTHON=1`, and Playwright is aligned to 1.64.1. (#360)
- **Breaking:** page extraction now uses one routed `web_fetch(url)` tool. The `tavily_extract_web_page`, `firecrawl_extract_web_page`, `exa_get_contents`, and `deepseek_fetch_web_page` builtin tools are removed. Configured sources are tried in `websearch_route` order with fixed provider defaults; plugins and Skills must call `web_fetch`. (#357)
- **Breaking:** outbound telemetry is removed. The `disable_metrics` setting and `ASTRBOT_DISABLE_METRICS` environment variable are gone; platform message counts are still written to the local statistics database for the Dashboard and are never uploaded. (#693)
- **Breaking:** the CUA and Shipyard Neo sandbox runtimes are removed. `computer_use_runtime` accepts only `none` or `local`; saved `sandbox` values migrate to `none`, and the retired `provider_settings.sandbox` block is dropped. (#694)
- Windows now defaults to the dependency-free NumPy `exact` vector backend because FAISS has no Python 3.15 wheels there; Linux and macOS keep FAISS, and DuckDB is skipped on Windows.
- Trace recording uses grouped `trace.*` settings (configuration revision 4); revision 5 retires the removed Computer Use runtimes. Legacy JSONL trace logs are not imported automatically.
- Configuration handling keeps fetched provider metadata across schema refreshes, initializes template `dict` fields to `{}`, treats redacted 2FA fields as unchanged, and restores the default chat model after stale per-session selections are cleared. (#10517, #10522, #10663)

### Fixed

- Security: tightened Dashboard authorization across API-key carriers, config routes, session targets, and step-up; required authorization before Open API WebSocket session creation; forced attachment delivery for file and file-token downloads; strengthened Lark signature/replay checks, Slack chunk limits, and shell environment validation; and extended credential redaction for errors, logs, and diagnostic exports. (#392)
- Providers and Agents: closed timeout, lifecycle, and stream-completion gaps; preserved background tool-result fragments and pending follow-ups; kept stopped command results decorated and delivered; preserved Coze stream tails and object-string history; restored DashScope key binding; and kept Gemini tool schemas free of non-string enums. (#672, #676, #678, #682, #10635)
- Platforms: resumed WeCom customer-service sync from a stored cursor, advanced it only after a full page, and tolerated overflowing timestamps; routed Telegram General-topic callbacks consistently; hardened Discord lifecycle and polling; kept Lark webhook runs alive; verified Misskey downloads with a temporary-session fallback; bounded Satori retries; and made DingTalk and Kook reconnects responsive to termination. (#675, #685)
- Files and knowledge bases: serialized chunked-upload assembly and guarded overlapping starts, recovered restart and cancellation states, and deleted attachment rows before unlinking files. Knowledge-base replacements now use crash-safe markers with roll-forward/rollback recovery, clear stale media, retry malformed cleaning replies, cap Markdown heading context and overlap against the chunk budget, and recognize pypdf filter arrays. (#420, #684)
- Pipeline and runtime: stopped command results are no longer dropped, blocked content stops before downstream stages, invalid rate-limit strategies are normalized, stage generators close on early return, buffered media is released on every exit path, and pending results are cleared on forced stop. Session waiters are admitted before route stop, and background tasks keep their ownership and cancellation semantics. (#672, #677, #682)
- Backup and storage: replace imports stay atomic and report failures; a directory restore now proceeds when any member fails instead of silently skipping it; moved attachments and configured vector indexes are restored; stale active import paths are tolerated; each main-database row imports in its own savepoint; and database migrations use portable JSON expressions with UTC statistics boundaries. (#684, #10644, #10661, #10664)
- Dashboard: bootstrap no longer remounts the app; thread streams abort on close; stale file, preview, log, step-up, and config responses are ignored; config saves are serialized; backup deletion and confidence parsing are guarded; the pip dialog stays visible in fullscreen; live-log SSE headers flush before waiting; and the version help activator regains focus. (#679, #10608, #10666)
- CLI and plugins: plugin updates now use unique hidden backups and restore the original directory on failure; editable symlink installs are refused for in-place updates; plugin rollback tasks keep scoped ownership; and removing a plugin register import preserves the trailing newline. (#457, #545)
- Help and diagnostics: remote help notices are size-limited, validated, and fail silently when unavailable; diagnostic exports handle symlinked log roots, oversized lines, and credential formats without leaking key bodies. (#673)

### Documentation

- Updated the bilingual guides for Python 3.15, routed `web_fetch`, the SearXNG Compose stack, wallpaper and appearance settings, persistent trace history, diagnostics export, backup coverage, CLI plugin-update safety, and the Windows vector-store default.
- The backup and diagnostics pages now describe archive contents, trusted-device handling, and export privacy limits in both languages.

### Maintenance

- Updated disclosed dependencies: pypdf 6.21.2, undici 7.30.1, fast-uri 3.1.9, katex 0.19.1, certifi 2026.10.19, and pip 26.2.2. (#670, #10670)
- Enabled all Ruff security rules, added project-review workflows, and recorded independent review decisions for upstream absorption in `upstream-decisions.jsonl`. (#366, #370, #393)
- Annotated intentional best-effort exception handling and cleared remaining CodeQL and strict-typing findings. (#687)

### Fork Adaptations

- Trace keeps the fork's grouped `trace.*` configuration, `schema_revision` 4, per-runtime session-waiter registry, sanitized log broker, and MDI-only Dashboard icons.
- Diagnostics and backup keep the fork's staged backup importer, SQLite stores, `tests/unit/dashboard` route tests, en-US/zh-CN-only locales, and in-app `/help/` documentation.
- The SearXNG stack follows the fork's source-build Compose contract. The optional nightly override remains the only prebuilt AstrBot image path.

### Fork Deviations

- Did not restore upstream Japanese or Russian locale catalogs, desktop update notices, dynamic plugin sidebar entries, installer scripts, mirrors, legacy `star/context.py`, or the monolithic Dashboard test. (#10614)
- Upstream release wording and upstream-only artifact links are not copied; this entry describes behavior present in this fork.

## 中文

本版本包含 **v4.29.1** 之后合入的变更。升级前请先阅读 **变更** 中的破坏性变更。

### 新增

- Dashboard 外观：壁纸与外观设置改为服务端保存，支持横屏和竖屏图库、上传校验与缩略图、壁纸主题色提取、打开时随机、定时轮换、多标签页同步，并改进表格、追踪、会话管理、授权和弹窗的移动端布局。壁纸素材和外观选择纳入 WebUI 备份。(#369)
- 追踪：消息追踪持久化到有容量上限的 SQLite 历史（`data/logs/traces.db`，目标 80 MB，保留 7 天），支持服务端搜索、筛选和分页。追踪页新增分组时间线、Tokens 用量、trace/span 日志关联和追踪数据清理；记录开关和容量配置位于 **设置 → 常规 → 日志**。(#10614)
- 诊断导出：新增 `导出诊断包` 操作和 `GET /api/v1/logs/export`，把磁盘及轮转日志、自定义日志路径、缓存日志、Trace 历史、配置与路由、插件状态和运行环境打包为一个 ZIP。可选择时间范围和脱敏模式；仅 Dashboard 管理员可下载，同一时间只运行一个导出。(#10418, #10659)
- 备份新增定时任务、模型用量统计、UMO 别名、OpenAPI 访问密钥和 MCP 服务配置。TOTP 受信任设备不写入备份，替换恢复时会清除目标实例的设备信任。(#10644, #10661)
- Docker：新增 `compose-with-searxng.yml`，同时启动 AstrBot 和仅在回环地址发布的 SearXNG 边车，自动生成设置并启用 JSON 搜索。实例地址填写 `http://searxng:8080`。(#686)
- ChatUI：SSE、重新生成和 WebSocket 请求现在会读取每次请求的 `flags`，正确控制流式输出、推理、内联 GenUI 和 ChatUI 默认系统提示词。(#365)

### 变更

- **破坏性变更：** 源码、CI 和容器基线统一为 Python 3.15.0，不再支持 Python 3.14 及更早版本。`silk-python` 改为按上游固定提交源码构建并使用 `USE-CYTHON=1`，Playwright 对齐到 1.64.1。(#360)
- **破坏性变更：** 正文抽取统一为按路由执行的 `web_fetch(url)` 工具，移除 `tavily_extract_web_page`、`firecrawl_extract_web_page`、`exa_get_contents` 和 `deepseek_fetch_web_page` 内置工具。已配置来源按 `websearch_route` 顺序尝试，抽取参数固定使用来源默认值；插件和 Skills 应改用 `web_fetch`。(#357)
- **破坏性变更：** 移除出站遥测。`disable_metrics` 配置项和 `ASTRBOT_DISABLE_METRICS` 环境变量不再生效；平台消息量等统计仍写入本地数据库供 Dashboard 展示，不会上传。(#693)
- **破坏性变更：** 移除 CUA 与 Shipyard Neo 沙箱运行时。`computer_use_runtime` 只接受 `none` 或 `local`；已保存的 `sandbox` 值会迁移为 `none`，并清理旧的 `provider_settings.sandbox` 配置块。(#694)
- Windows 默认使用无额外依赖的 NumPy `exact` 向量后端，因为 FAISS 暂无 Python 3.15 轮子；Linux 和 macOS 仍默认 FAISS，Windows 跳过 DuckDB。
- 追踪使用分组 `trace.*` 配置（配置修订 4）；配置修订 5 会清理已移除的 Computer Use 运行时。旧 JSONL 追踪日志不会自动导入。
- 配置刷新后会保留已获取的模型元数据，模板 `dict` 字段初始化为 `{}`，已脱敏的二次验证字段按未修改处理；清除过期的会话模型选择后会恢复默认聊天模型。(#10517, #10522, #10663)

### 修复

- 安全：收紧 Dashboard 对 API Key 载体、配置路由、会话目标和二次验证的授权；Open API WebSocket 在创建平台会话前先鉴权；文件和文件令牌下载强制使用附件响应；加强 Lark 签名/重放校验、Slack 分片上限和 Shell 环境变量校验；并扩展错误、日志和诊断导出中的凭据脱敏范围。(#392)
- Provider 与 Agent：补齐超时、生命周期和流结束处理；保留后台工具结果片段和待处理追问；被停止的指令结果仍会装饰并发送；保留 Coze 流尾部与 object_string 历史；修复 DashScope Key 绑定；避免向 Gemini 工具 schema 发送非字符串枚举。(#672, #676, #678, #682, #10635)
- 平台：企业微信客服消息从已保存游标续传，整页同步完成后才推进游标，并容忍溢出的时间戳；Telegram General 话题回调保持一致路由；加固 Discord 生命周期与轮询；保持 Lark Webhook 运行；Misskey 下载改用临时会话回退校验；限制 Satori 重试；DingTalk 与 Kook 重连可及时响应终止。(#675, #685)
- 文件与知识库：串行化分片上传组装并阻止重叠开始，恢复重启和取消后的状态，删除附件时先删数据库行再删文件。知识库替换使用崩溃安全标记并支持前滚/回滚恢复，清理过期媒体，重试异常清洗回复，按分块预算限制 Markdown 标题上下文与重叠，并识别 pypdf 的过滤器数组。(#420, #684)
- Pipeline 与运行时：停止后的指令结果不再丢失，被拦截内容会在下游阶段前停止，非法限流策略会归一化，阶段生成器在提前返回时关闭，缓冲媒体在每个退出路径释放，强制停止时清空待处理结果。会话等待者在路由停止前准入，后台任务保持归属和取消语义。(#672, #677, #682)
- 备份与存储：替换导入保持原子并上报失败；目录恢复在任一成员失败时不再静默跳过；恢复移动过的附件和已配置的向量索引；容忍残留的导入路径；主库逐行使用 savepoint 导入；迁移改用可移植 JSON 表达式，统计边界按 UTC 计算。(#684, #10644, #10661, #10664)
- Dashboard：启动不再重复挂载应用；关闭面板会中止线程流；忽略过期的文件、预览、日志、二次验证和配置响应；配置保存串行化；备份删除和置信度解析增加保护；全屏控制台中的 Pip 弹窗保持可见；实时日志 SSE 先刷新响应头；版本帮助入口恢复焦点。(#679, #10608, #10666)
- CLI 与插件：更新插件时使用唯一的隐藏备份，失败时恢复原目录；editable 符号链接安装会拒绝原地更新；插件回滚任务保持作用域归属；移除插件注册导入时保留末尾换行。(#457, #545)
- 帮助与诊断：远程帮助通知增加大小限制和校验，不可用时静默失败；诊断导出正确处理符号链接日志根目录、超长日志行和多种凭据格式，不泄露密钥正文。(#673)
