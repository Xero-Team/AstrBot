## [4.28.1] - [WIP]

### Added

- Mount instance-scoped high-risk tools on IM when the sender is bound as
  `instance_operator` or above on that config, without Dashboard step-up.
  `/session info` exposes the authorization subject for that binding. (#85)
- Add dedicated OpenCode Go Chat Completions, Messages, and Responses
  Provider types. Do not retarget official OpenAI, Anthropic, or OpenAI
  Responses sources at the Go API Base. (#82)
- Align personal WeChat (`weixin_oc`) with the official openclaw-weixin
  channel: QR pairing, IDC redirect, Silk outbound voice, quote
  reconstruction from local cache, 4000-character text split, tool-call
  progress items, and streaming coalesce. (#80)
- Assemble the main-agent tool catalog once from Skill `tools:`, Persona
  policy, and social-surface hard-strip. `read_skill` reads a frozen
  request snapshot; `SKILL.md` no longer implies Shell. (#73, #75)
- Export `TextPart.mark_as_temp` on `astrbot.api.provider` so plugins can
  append request-only extra user content without importing `astrbot.core`.
  (#83)

### Changed

- Route `prompt_prefix`, cron/background wake prompts, and tool-loop
  notices through one logic-free `{{name}}` interpolator. T2I Jinja2 stays
  isolated. (#74)
- Skill frontmatter `tools:` is a filter of registered names, not a grant.
  Community `allowed-tools` is ignored. (#73)

### Fixed

- Send the OpenCode Go session header on auxiliary Provider calls. (#82)
- Keep Weixin OC streaming and media sends on the official channel path.
  (#80)
- Treat a missing `prompt_prefix` template as empty instead of failing.
  (#74)
- Freeze Skill snapshot files, lock catalog reingest, lock sandbox reads,
  and strip tools that were never stepped. (#73)
- Ignore macOS ``PermissionError`` when signalling an already-exited
  managed-shell process group during shutdown.

### Documentation

- Document OpenCode Go source types under `/providers`.
- Document Weixin OC official-channel login, media, quotes, and streaming.
- Document Skill catalog assembly, `read_skill`, and IM
  `instance_operator` instance tools.
- Document plugin relative imports, stacked command-filter AND, and
  `TextPart.mark_as_temp` on the plugin SDK guides.

### Maintenance

- Bump Python, Dashboard, and docs dependencies. Keep TypeScript 6.0.3
  because vue-tsc still lacks TypeScript 7. Cap `websockets` below 16 for
  lark-oapi and `mcp` below 3. (#71)

### Fork Deviations

- Did not apply upstream desktop-managed stale WebUI rejection (#9898).
  This fork does not ship AstrBot Desktop or download Dashboard packages.
- Upstream release wording and upstream-only artifact links are not copied
  verbatim; this changelog describes the features present in the fork.

## 中文

### 新增

- IM 发送者在该配置上绑成 `instance_operator` 及以上时，挂出实例级高风险
  工具且不走 Dashboard step-up。`/session info` 给出用于绑定的授权主体。
  (#85)
- 新增 OpenCode Go Chat Completions、Messages、Responses 三个专用来源。
  不要用官方 OpenAI / Anthropic / OpenAI Responses 改 API Base 去接 Go。
  (#82)
- 个人微信（`weixin_oc`）对齐官方 openclaw-weixin：扫码配对、IDC 跳转、
  Silk 出站语音、本地缓存还原引用、4000 字拆分、工具进度条、流式合并。
  (#80)
- 主 Agent 工具目录一次装配：Skill `tools:`、人格策略、社交表面硬裁。
  `read_skill` 读请求级冻结快照；`SKILL.md` 不再隐含 Shell。 (#73, #75)
- 插件 SDK `astrbot.api.provider` 导出 `TextPart.mark_as_temp`，可追加仅
  本轮的 extra user content，不必导入 `astrbot.core`。 (#83)

### 变更

- `prompt_prefix`、定时/后台唤醒提示和工具循环通知统一走无逻辑
  `{{name}}` 插值。T2I 仍用 Jinja2。 (#74)
- Skill 前言 `tools:` 只过滤已注册工具名，不是授权。社区
  `allowed-tools` 会被忽略。 (#73)

### 修复

- OpenCode Go 辅助调用也带 session 头。 (#82)
- 个人微信流式和媒体发送走官方通道。 (#80)
- 缺少 `prompt_prefix` 模板时视为空字符串。 (#74)
- 冻结 Skill 快照文件，锁定目录再摄入和沙箱读取，并去掉未步进工具。
  (#73)
- 托管 shell 关闭时忽略 macOS 上已退出进程组的 ``PermissionError``。

### 文档

- `/providers` 补充 OpenCode Go 专用来源。
- 个人微信官方通道登录、媒体、引用和流式说明。
- Skill 目录装配、`read_skill`，以及 IM `instance_operator` 实例工具。
- 插件相对导入、指令过滤器 AND、以及 SDK 上的 `TextPart.mark_as_temp`。

### 维护

- 升级 Python、Dashboard、文档依赖。TypeScript 仍钉 6.0.3（vue-tsc 尚未
  支持 TypeScript 7）。`websockets` 低于 16 以适配 lark-oapi，`mcp` 低于
  3。 (#71)

### Fork 差异

- 未吸收上游桌面托管过期 WebUI 拒绝 (#9898)。本 fork 不发布 AstrBot
  Desktop，也不下载 Dashboard 包。
- 不原样复制上游发布说明和仅属于上游的产物链接；本 changelog 只描述 fork
  中实际存在的功能。
